# Privacy & Security

This project is intentionally private because it is built around a real person's likeness and private media.

## Never commit

- Raw personal photos
- Edited training photos
- Private reference photos
- Partner/reference-person photos
- Generated private/adult media
- Model checkpoints or LoRA weights
- API keys
- Cloud credentials
- Cookies or session tokens
- Private metadata that identifies locations or accounts

## GitHub is for the system

The repository should contain documentation, configurations, prompts, experiment notes, workflow definitions, and other reproducible project information.

Large/private assets belong in controlled external storage.

## Before making the repo public

Review the entire history, not just the current working tree. A file removed in a later commit may still exist in Git history.

Do not make the repository public until private media, credentials, personal metadata, and restricted model files have been verified absent from the full history.
