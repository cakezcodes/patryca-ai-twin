# Reference Photos

Reference images are kept separate from the Person LoRA training dataset.

## Suggested private categories

```text
private-reference-photos/
├── clothing/
├── lingerie/
├── jewelry/
├── rooms/
├── props/
└── other/
```

Use clear filenames and a simple inventory so the correct reference can be found quickly during generation.

Actual private reference images should remain outside this repository.
